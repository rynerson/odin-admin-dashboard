WHAT: This project involved developing a dashboard for a user in HTML and CSS using Grid for responsive layout.
WHY: This project strengthened my knowledge of CSS Grid and allowed me to implement CSS Grid in a real-world project.
HOW: I started by laying out the overall structure of the site in Grid. I then started developing the sidebar, header, projects, announcements, and trending areas.
I developed grid containers within those sections for responsive layout.
TOOLS USED: HTML, CSS, Laptop, Linux(Ubuntu).
